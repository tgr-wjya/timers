# Universal Timer CLI (`timer`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a terminal-agnostic, cross-platform CLI timer tool in Go with human-friendly duration parsing, concurrent background daemon, Pomodoro stage cycles, desktop notifications, audio chimes, and persistent SQLite analytics.

**Architecture:** Single static Go binary (`timer`). CLI commands communicate over a local Unix domain socket (or Windows pipe) with an auto-spawning background daemon. The daemon manages zero-drift timers, drives Pomodoro state machines, plays chimes (PipeWire/Pulse/macOS/Windows/embedded fallback), fires desktop notifications, and persists completed sessions into pure Go SQLite. A foreground watch mode renders Style 4 (Unicode clock glyph + continuous filament gauge + OSC 2 window/tab title).

**Tech Stack:** Go (Go 1.24+), `modernc.org/sqlite` (Pure Go SQLite, CGO_ENABLED=0), Linux PipeWire/PulseAudio (`pw-play`/`paplay`), FreeDesktop notifications (`notify-send`), XTerm OSC 2 terminal title sequences.

**Spec:** [`docs/superpowers/specs/2026-10-16-timer-cli-design.md`](file:///home/tgr-wjya/Documents/Projects/timers/docs/superpowers/specs/2026-10-16-timer-cli-design.md)

## Global Constraints

- Language: Go with pure Go dependencies (`CGO_ENABLED=0` compatible, zero GCC requirements).
- Storage: Standard XDG paths (`$XDG_DATA_HOME/timer/timers.db`, `$XDG_RUNTIME_DIR/timer/timer.sock`).
- Terminal: Standard ANSI VT100 / XTerm OSC 2 escape sequences; non-TTY fallback when stdout is piped.
- Non-blocking: Audio chimes and notifications must run asynchronously and never block the timer ticker or SQLite transactions.
- Zero Clock Drift: Absolute target timestamps (`TargetEnd = StartedAt + Duration`) used for scheduling.

## Review Focus

1. **Ambiguous or bare number durations (e.g. `timer 90`):** Must return a helpful error asking if the user meant `90s` or `90m`, not silently fail or default to raw nanoseconds.
2. **Stale daemon socket cleanup:** If daemon process was killed forcefully, next CLI run must detect dead socket, remove it, and auto-spawn a fresh daemon without user intervention.
3. **Pipe / Non-interactive stdout (`timer list | grep` or redirect):** Must not output ANSI clear-line or OSC 2 window title codes that would corrupt piped streams.
4. **Desktop notification / Audio failure resilience:** If `notify-send` or `pw-play` is missing or fails, daemon must fall back gracefully to embedded chime / ASCII BEL (`\a`) without crashing or aborting the timer.
5. **System sleep / suspend recovery:** If machine is suspended past the timer's `TargetEnd`, waking up must trigger the completed alert immediately and log the accurate duration in SQLite.
